# Form Filler — pages

Static pages opened by the Form Filler Chrome extension (GitHub Pages):
- `welcome/` — opened once after install (three steps to pin the extension);
- `uninstall/` — opened after removal, optional feedback sent to a Google Form.
- `feedback/` — opened by a 1–3 star rating in the popup; the answer goes to the Google Form "Form Filler — feedback".
- `test-form.html` — sample form for Chrome Web Store reviewers (see store/moderator-note.md of the extension).

Privacy policy: separate repository `form-filler-privacy`.
Illustrations: `tools/shots.html` → `node tools/render-shots.js` → `welcome/steps-1-2.png`, `welcome/step-3.png`.
